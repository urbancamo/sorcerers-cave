# Spec Tasks — Combat Revision M0 to M2

These are the tasks for milestones M0–M2 of [2026-10-03-combat-revision-technical-spec.md](2026-10-03-combat-revision-technical-spec.md) §10.1. They are the prerequisites for the stranger-pairing network ([requirements](2026-10-04-nn-stranger-pairing-requirements.md) §10).

> Created: 2026-10-04
> Status: Draft for review
> Format: Agent OS (tests first, verify last). Six major tasks rather than five, because M2 is large.

## Ground rules

- Everything new sits behind the per-game flag `variants.combatRevision` (Q-T1, default off). With the flag off, **every existing test and golden must stay unchanged** — that is the safety net.
- Every change under `packages/engine/src` updates `docs/specs/engine-spec.md` in the same change (project CLAUDE.md): new `SC-CMB-*` rows, narrative, appendices, gap list.
- Size key: **S** a day or two, **M** about a week, **L** two weeks or more (estimates, to be recalibrated after Task 2).

## Already done (Stage 1, branch `stranger-loadout`, merged as PR #10)

Do **not** rebuild these. New code must reuse them:

- `capabilities.ts` — the "uses artefacts as" table (I13, spec §4.4.2).
- `loadout.ts`, `strangerEquip.ts`, `strangerGear.ts` — Peter's V2 default loadout and `FightState.gear`.
- Area-wide Eye in the fight strength calculations (I14, spec §4.4.3).

Caveat: these are always on and **not** flag-gated, and the capability table and floor Eye also reach multiplayer fights through the shared strength functions. Task 1 decides whether to gate them.

```
Task 1 (M0 sign-off) ──► Task 2 (model, artefacts, strength) ──► Task 3 (legality) ──┐
                                      │                                               ├─► Task 5 (round engine) ──► Task 6 (standard strategy, CLI)

```
