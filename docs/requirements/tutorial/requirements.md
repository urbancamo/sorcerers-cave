# Tutorial Requirements

Peter has written a set of requirements that we are to implement as a tutorial:
[Tutorial Game Script.pdf](Tutorial%20Game%20Script.pdf)

The tutorial should be offered on the new game menu, and suggested the first time a browser connects to 
Sorcerer's Cave. The tutorial should cover all the main game mechanics to educate a new player on how to 
play the game, without venturing into advanced tactics.

Enter plan mode to determine how best to implement the tutorial, using UI best practices, and provide suggestions,
asking any clarification questions you need to. Sanity check Peter's list and provide any suggestions of other 
functionality that a new player might require that hasn't been listed.
