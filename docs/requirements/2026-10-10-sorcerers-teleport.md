# Sorcerer's Teleport

Research implementing the Sorcerer's teleport option.
The player, having defeated the Sorcerer, should have the option of sparing him in return
for a teleport to any area card already discovered in the Cave.

The UI should allow the player to select an arbitrary area tile to teleport to, and there
should be an impressive effect play as the player's party is transported to the new
location.
