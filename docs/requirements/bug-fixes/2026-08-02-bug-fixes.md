# Bug Fixes, 02/08/2026

## Incorrectly drawing small cards on CHASM area

TEST RESULT: The play tester entered the CHASM area and a small card was drawn on level 1.

EXPECTED OUTCOME: No cards should be drawn when entering the CHASM area.

## Unicorn reaction roll

TEST RESULT: reaction roll is displayed when testing friendliness of Unicorn.

EXPECTED OUTCOME: Unicorn reaction depends solely on there being a female in the party,
so no need to display a reaction roll.

## DEEP POOL - actions unavailable

TEST RESULT: party is at an entrance to the DEEP POOL where heavy treasure has been dropped.
There is no option to pick up the heavy treasure.

EXPECTED OUTCOME: If there is HEAVY TREASURE in the location the party is at there should be an option to pick up the treasure, as per the normal pickup rules and UI.
