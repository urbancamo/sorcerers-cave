## Resolution (2026-08-05)

**"Drop into chamber" text — fixed.** The Party panel's drop button was a hardcoded label
regardless of the party's actual tile (chamber, tunnel, Gateway, or a Precise-Locations special,
where a drop instead sinks into a sub-location). Changed to "Drop here" everywhere
(`apps/web/src/game/PartyPanel.tsx`).

**Demon forcing an instant fight with no Withdraw/Attack/Test menu — investigated, no change.**
The original design doc (`docs/requirements/extension-kit/2026-07-26-engine-integration-design.md`,
US-13) specifies this outright: "entering (or withdrawing into) the demon's area forces an
encounter" / "leads into a demon fight." No reaction table (hostileMax/indiffMax) was ever defined
for the Demon, unlike every other reactive creature (Apprentice, Unicorn, Dragon, Sorcerer,
Spectre) — a strong signal it was never meant to roll one. That doc's own "like Spectre" language
is scoped narrowly to two things: the magic-only combat-engagement gate, and the
auto-slay-the-strongest-when-unengageable rule — never to the reaction-test/encounter-menu flow.
(Spectre itself, absent the Eye/Talisman, DOES go through the normal encounter menu — but that's
not what "like Spectre" referred to here.) Confirmed with the designer: the instant ambush is the
correct, original, deliberate design; no engine change made. The existing `demonUnfolds` notice
("The Demon unfolds from the shadows.") already narrates the ambush clearly.
