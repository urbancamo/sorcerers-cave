# Engine & UI Integration - Planning and User Stories

Write a plan for the engine integration of the extension kit. This will require you to write detailed
plans for each of the new types of area card, creature, treasure, artifacts and hazards. The instructions provided
for each of these cards relates to a human board-game variant, not this computer variant of the game.

You must define the interaction between the player and both the UI and game engine for each of these new variants.
This will require underlying data changes.

You must both enforce the rules, create the gameplay, and display the outcomes for each. Pay special attention to
the User Interface - in the past the gameplay has been well defined in the engine but poorly relayed to the user.
I suggest creating a user story that covers each of the possible interactions between the player and the new card.
The user story should describe the impact of drawing the card on the user, how the interaction plays out with the 
user interface, the immediate outcome including feedback, and any impact on future game events and score.

Create one user story for each card, and use a standard format for the interaction description.
