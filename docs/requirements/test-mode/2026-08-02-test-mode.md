# Test Mode

Test mode will allow a tester to check specific scenarios in the game state. For example, entering
a special chamber from a specific direction, use of specific artifacts in a scenario or 
combating specific creatures.

We need a test mode that will allow the following:

- choose the next area, specifically one of the special cards from either the standard or extension
  pack
- choose artifacts or creatures to appear in a chamber
- choose whether creatures are friendly, indifferent or hostile

Test mode should be driven by specifying a 'magic string' as a parameter to the application URL,
for example https://sorcerers-cave.vercel.app/test=abcd

The magic string should be a UUID that is specified in such a way that it isn't stored in the 
application, for example in the environment.

Plan this first.
