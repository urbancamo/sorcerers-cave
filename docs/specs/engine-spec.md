# The Sorcerer's Cave — Engine Specification (v2)

> **Status:** Living specification of the game-logic engine (`packages/engine`), regenerated 2026-07-01 from the code and its git history.
> **Source of truth:** the engine **code** is authoritative. Where this document and the code disagree, the code wins — treat the discrepancy as a spec bug.
> **Scope:** the pure, deterministic game rules in `packages/engine/src` — data model, RNG, turn lifecycle, movement, chambers, encounters, fights, special areas, artifacts, scoring, and the multiplayer seat model. The React/Three.js client, the Convex backend, and logical UX (v1 §2/§13) are **out of scope** here.
> **Supersedes:** `docs/specs/design-spec.html` (v1), whose §15 "Gap Analysis" and §16 "Implementation Sketches for the Open Gaps" are obsolete — nearly all those gaps are now implemented. See **Appendix B** for the corrections.

## How to read this document

- **Part I — Normative Requirements** is the testable contract: one rule per row, each with a stable **ID**, the authoritative **`file:line`**, and the **test** that pins it (`—` = no direct test; consolidated in Appendix C).
- **Part II — Rules Narrative** is the readable rulebook, cross-referencing requirement IDs in parentheses, e.g. (SC-8.3-5).
- **Requirement IDs** are `SC-<§>-<n>`, stable across edits and aligned with the code's `spec §N` comments. `§MP` = multiplayer.
- **Appendices:** A — data tables & constants (incl. the RNG algorithm and the full state shape); B — corrections vs the v1 spec; C — test-coverage gaps; D — cross-implementation conformance vectors (for ports).

# Part II — Rules Narrative

## §3 / §5 Data model & randomness

Sorcerer's Cave is built on two fixed card decks and one seeded random number generator, all held as plain data so a game replays identically from its starting seed. The **large pack** is a set of 61 area cards, each a single integer whose bits encode which of the four compass doorways exist, whether the card is a chamber, whether it has a stair up or down, and which of six "special" area types it is (SC-3-1, SC-3-2). One of those cards, index 21, is the Gateway (value 175) where the party starts; it is lifted out and the remaining 60 are shuffled into the exploration deck (SC-5-10). One data correction matters: card index 41 is an east–west corridor with a stair up (value 42), not the east–west-with-stair-down value the original spec listed, because the latter has no matching tile art (SC-3-3).

The cast is 14 creature types with fixed statistics — fighting strength, magical power, carry capacity, point value, behaviour flags, and reaction thresholds (SC-3-5, SC-3-6). Only the first eight (ids 0–7) can be chosen for the starting party; the rest, from Wizard through Unicorn, appear only inside the cave (SC-3-7). Fifteen treasures (three heavy metals, a heavy chest, eleven weightless artifacts) and five hazards round out the entities (SC-3-10, SC-3-12).

The **small pack** is the deck drawn inside chambers, and it is deliberately a *single finite deck* of 71 cards — 37 creatures, 27 treasures, 7 hazards (SC-3-13 … SC-3-16). Crucially, the same pack supplies both the player's starting party and the strangers met later: when the player builds a party those exact creature cards are removed from the shuffled pack, so a creature taken into the party can never also turn up as a cave stranger (SC-5-5). Party selection is validated against a 6-point budget and per-creature stock limits (SC-5-1, SC-5-2, SC-5-3) — resolved through `selectionCost`/`startingStock` (§EXT) so a kit-on game's five extra starters, revised Ogre/Troll costs, and raised Woman/Dwarf stock apply automatically, while a kit-off game validates exactly as it always has (SC-EXT-29).

Randomness comes from one linear-congruential generator using the classic glibc constants: the seed advances as `seed × 1103515245 + 12345 mod 2^31`, computed with big integers so nothing overflows (SC-5-6). Every random result reads the *upper* bits (15..30) of the new seed rather than the low bits; a d6 divides that 16-bit value into six equal buckets, and `randBelow(n)` takes it modulo n (SC-5-7, SC-5-8). Shuffling is Fisher–Yates walking from the last index down to the second, and it is pure (SC-5-9). Because the whole engine threads its RNG state through the single `seed` field and never calls the clock or `Math.random`, any game is perfectly reproducible (SC-5-13). Setup pins the consumption order: shuffle the large pack from the given seed, shuffle the small pack from the resulting seed, then store that final seed as the game's live RNG state (SC-5-12).

## §4 The turn lifecycle & action/event contract

The engine runs as a pure reducer: every player decision is a `GameAction`, and `reduce(state, action)` returns a fresh `{ state, events }` pair, where `events` is the authoritative record of what happened (SC-4-1). The UI never infers game facts — it renders only what the reducer emits. Once the game has ended, the reducer is inert (SC-4-2). The one field that governs everything the player can do is `phase`: explore, encounter, fight, pickup, or gameOver (SC-4-3). The interactive contract is that `legalActions(state)` and `reduce` agree exactly — the selector enumerates the actions the UI may present, and the reducer accepts precisely those, rejecting anything else with a `blocked` (or `planRejected`) event and no state change (SC-4-4, SC-4-6). Quitting is a phase-agnostic HUD action, never an in-menu item (SC-4-5, SC-4-7). When resolving an action relocates the party after the current area's events already fired (a trap fall, a whirlpool drag, a chasm or crypt descent), the result additionally carries a presentation-only `midState` snapshot of the interrupted room, so the UI can show those events where they actually happened before revealing the landing (SC-4-43).

A turn begins in explore. `move` is the only turn-advancing action: a success increments `turn` and hands off to area resolution, while a dead end or blocked direction consumes no turn (SC-4-9). Area resolution always announces `moved`, then decodes the tile: a chamber draws its contents and runs hazards in fixed order, folding in Eye-of-God annihilation and Talisman warding (SC-4-11, SC-4-12). A trap fall parks the chamber behind, drops the party one level in the same turn, and can chain (SC-4-14). If the dust settles with strangers present the phase becomes encounter (or an immediate fight if the party once fled here); with only treasure it becomes pickup; otherwise the party rests back in explore (SC-4-15). Surprise is a one-shot flag set only on a genuinely fresh, non-trap entry (SC-4-16).

From encounter the party may withdraw, attack, or test (SC-4-17, SC-4-18, SC-4-22); combat lives in fight, driven by a submitted pairing (`resolveRound`) that resolves one round and either pauses for a `chooseCasualty` decision or finalises (SC-4-24 … SC-4-26); after round one the party may retreat by any exit, marking the abandoned chamber hostile (SC-4-27, SC-4-28). pickup handles `takeTreasure` (with the Lost-Ruby statue fight), `leaveTreasure`, and `retakeDropped` (SC-4-29 … SC-4-31). Treasure redistribution, `useArtifact`, and `openChest` are gated by phase and eligibility (SC-4-32 … SC-4-35). The full action catalog is 22 actions and the event catalog 63 events, both defined in `actions.ts` and produced solely by the reducer (SC-4-41, SC-4-42).

## §6 Map, movement & levels

The cave is a stack of levels, each a sparse grid addressed by a single packed integer `level*10000 + y*100 + x` (SC-6-2). A move names a direction and steps one unit (SC-6-3); it is first validated against the current card's decoded bitfield — no exit or stair in that direction means nothing happens (SC-6.1-1). `tryMove` is pure, cloning state so a rejected move never corrupts the game (SC-6-5). If the destination is already occupied, the party walks there without drawing; a lateral step still requires the destination card to show the reverse doorway, while a stair step always connects (SC-6.1-2, SC-6.1-3). An earthquake-collapsed neighbour is impassable rubble — the doorway onto it is pruned and the move dead-ends (SC-6.1-5).

When the destination is unexplored, the engine draws the next large-pack card (SC-6.1-7), or reports a bloodless failure if the pack is spent (SC-6.1-6). A connecting card is laid face-up and entered (SC-6.1-8); a non-connecting card is laid face-down but recorded (enterable later from another direction), and the doorway tried is pruned so the same doomed direction is never offered twice (SC-6.1-9, SC-6.1-10). Cards are always placed in printed orientation — the engine never rotates a tile (SC-6.1-11).

Vertical travel carries three rules. A printed stair-up on any level-1 card is a **cave exit**, kept as drawn — the rules state "any stairway leading up from the first level is an exit from the Cave," so the Gateway is not the only way out; a party whose Gateway is destroyed can still escape by finding another up-stair. Exiting is the `exitCave` action (a DIR_UP *move* stays blocked on level 1, so no level-0 area is ever created) (SC-6.1-12). Secret doors: descending onto a card with no printed stair-up, or ascending onto one with no printed stair-down, mirrors the missing stair so the party can retrace, tags it `mirroredStairs` (a link, not drawn art), and lays a numbered secret-door marker (SC-6.1-13, SC-6.1-14, SC-6.1-16). This holds whether the far tile is freshly drawn or was explored earlier — climbing or descending into an already-placed area mirrors the return stair too, so a party can never be stranded a level away with no way back (SC-6.1-17). Leaving the cave is a distinct action: on level 1 with a visible stair-up, `exitCave` ends the run as ESCAPED, with no return (SC-6.2-1, SC-6.2-2). The one rulebook feature deliberately omitted is the "forced redraw" out of a total dead-end deadlock, so a fully boxed-in tunnel can soft-lock (SC-6.3-1). Two paths bypass door checks: a trap drops the party straight down with no climb-back (SC-6-6), and the Magic Carpet teleports one tile ignoring doors but never out of the cave (SC-6-7).

## §7 Chambers, draws, hazards & pickup

On a party's first visit to a chamber, the engine draws `min(level, 4)` cards from the small pack (SC-7.1-2); the Tomb of Kings adds one and the Great Hall two, capped at eight (SC-7.1-3). Each card is sorted by its numeric band into strangers, treasure, hazards, or sleepers (SC-7.1-5). A revisit never redraws — it reloads whatever was persisted on the tile (SC-7.1-6), and every entry resets the working set and the indifference streak (SC-7.1-7).

Hazards resolve before anything else in a fixed priority: Earthquake, Medusa, Ghouls, Mutiny, Trap (SC-7.2-1) — with one interactive exception: if Medusa is among them and a living member holds Lotus Dust (and nothing already neutralises her), the entry suspends in the `medusa` pause for a single decision — throw the dust, putting her to sleep for two of the player's turns, or proceed and brave the gaze (SC-7.2-14, SC-7.2-15, SC-11-42). An Earthquake collapses the *previous* tile — flagged destroyed, contents wiped, a scar laid on it — sealing the way back (SC-7.2-2, SC-7.2-12). Medusa rolls 1d6 against each living member; a 1 or 2 turns that member to stone, pinned to the chamber, unless a Wizard bearing the Magic Staff averts her gaze entirely, or her Lotus sleep still holds (SC-7.2-3, SC-7.2-4). Ghouls force every member to drop heavy treasure and then fight at strength 2, unless a Talisman-bearer wards them off (SC-7.2-5 … SC-7.2-7). Mutiny sends every ally deserting back into the stranger pool, except that an all-ally party keeps one loyal (SC-7.2-8). A Trap drops the whole party one level, one-way, unless a Dwarf guides them past (SC-7.2-9). Medusa and Ghouls lurk — re-parked to fire again on every re-entry — while the Earthquake scar never re-fires, and petrified members are freed on return by a staff-bearing Wizard (SC-7.2-10, SC-7.2-11).

With the room clear, the party may pick up treasure. Carrying is bounded by weight alone (heavy items 25 kg, the Chest 100 kg; artifacts weigh nothing), checked against each creature's capacity (SC-7.3-1, SC-7.3-2). Pickup is a per-item choice; taking the last item or leaving the rest parks the remainder for later (SC-7.3-4, SC-7.3-5). Members may drop items to free capacity or move them between living members (SC-7.3-6, SC-7.3-7). Treasure dropped or left on the floor is never lost: it parks on that tile and is offered again when the party returns — whether the tile is a chamber or a bare tunnel, so treasure set down in a passage to avoid a Deep-Pool crossing can be picked back up (SC-7.3-5, SC-7.3-12). The Lost Ruby is guarded by a strength-8 statue that must be wrestled — and a wrestler the statue slays spills his carried goods into the pickup (SC-7.3-9) — and heavy treasure dumped to fight is reclaimed after a win (SC-7.3-10). An item is either merely *carried* or — for the Magic Sword, Magic Staff and The Ring alone — *borne*: wielded, worn or displayed via the `setBorne` party-panel action, and stowed again by handing it over or dropping it (SC-7.3-13). The distinction never touches combat arithmetic; it decides only what happens when the holder falls. Death and petrification affect the living flesh, so a victim's carried items spill onto the chamber floor to be taken like any find, while a borne item goes down with the body — petrified with a stone member (returned intact on revival) or lost with a corpse (SC-7.2-13, SC-7.3-14, SC-9.5-11). If strangers stay merely indifferent, their treasure stays guarded and no pickup is offered, though the party may still attack (SC-7.3-11).

## §8 Stranger encounters

When a party enters an occupied chamber, play stops at the encounter phase and it must commit to withdraw, attack, or test (SC-8.1-1, SC-8.1-2). Attacking immediately is the only way to seize surprise: a fresh, non-trap entry sets `surpriseReady`, and attacking then opens the fight +1; any delay, or choosing to test, forfeits that edge (SC-8.1-5, SC-8.1-6). Withdrawal steps back to the prior tile, leaving the strangers behind — but it is barred with no way back (up a trap fall, or into an earthquake-collapsed tile) (SC-8.1-3, SC-8.1-4).

To test reaction, the engine finds the group's leader — the stranger of highest leader-priority, ties to the first drawn (SC-8.2-1) — and the whole group reacts as that leader does (SC-8.2-2). One d6 is rolled, +1 for any living charismatic member and −1 per active curse, then clamped to 1–6; but a natural 1 always counts as 1 (SC-8.3-2 … SC-8.3-5). The adjusted roll is read against the leader's thresholds: hostile, indifferent, or friendly (SC-8.4-1). Hostile throws the party into a fight with surprise to the strangers (SC-8.4-2); friendly recruits every stranger as an ally, added to the party in full with no size cap — the original rules impose no party-size limit (SC-8.4-7); an indifferent result advances a streak, and the third consecutive indifferent permanently pacifies the chamber for this party (its guards and treasure parked, the party freed to leave) (SC-8.4-3, SC-8.4-4). The streak is per-visit and the whole indifference state is tracked per party (SC-8.4-5, SC-8.4-6).

Several creatures bend the rules: the Sorcerer is hostile on every roll (SC-8.5-1); the Dragon is never friendly (SC-8.5-2); the Spectre is annihilated by the Eye or warded by the Talisman before the reaction is rolled (SC-8.5-3); the Unicorn is always friendly but only *joins* a party with a living Woman, otherwise guarding and pacifying the area (SC-8.5-4, SC-8.5-5); and a Charmed Flute lulls every Dragon on entry so a gentler creature leads (SC-8.5-6). A pacified chamber may be traversed freely but may still be attacked to win the guarded treasure, with no surprise (SC-8.5-7).

## §9 Fights

A fight is fought one round at a time, each round driven by an explicit battle plan the player submits (SC-9.1-1). A plan is a list of matches; each sends one or two living members to the front against one or two strangers, optionally with caster backers behind. The engine validates hard before dice: no empty plan (bar the forced-Spectre case), no two-against-two, backers must be casters by type, every index used once, and every stranger a still-free *capable* fighter could fight is engaged — a Spectre only counts against a free caster/sword-bearer, so a sole caster may down one Spectre and leave a second rather than deadlock (SC-9.1-3 … SC-9.1-9). When out-numbered, the §395 "strongest combination" kicks in — foes gang onto lone fighters and leftover enemy casters fold their magic into the focus match (SC-9.1-10, SC-9.1-11).

Strength is the heart of resolution: a fighter's total is its fighting strength plus dragon-slayer bonus plus Magic-Sword plus an active Strength Potion, and a Priest or Wizard fighting hand-to-hand fights at its *total* strength (SC-9.3-1). Backers add magical power only. Two adjustments ride the die instead: The Ring gives +1 to every party roll and each curse subtracts one — though a curse stops biting once the Sorcerer dies (SC-9.3-6, SC-9.3-7). Surprise (+1) applies to round one only (SC-9.2-1). Each side rolls one d6; higher total slays the strongest creature in the losing group, a tie kills no one (SC-9.3-8 … SC-9.3-10).

Special rules overlay this: a Spectre can only be fought with magic or a Magic Sword, and an un-fightable idle Spectre simply slays the strongest member (SC-9.4-1, SC-9.4-4); felling a Dragon truly single-handed earns a permanent +1 (SC-9.4-7); the Sorcerer is weakened but never neutralised by the Eye and Lotus Dust (SC-9.4-8); and an active Eye of God nullifies every magic and artefact bonus on both sides, the Sorcerer excepted (SC-9.4-9). Before fighting, front-line fighters drop heavy treasure to the floor so it is not lost if they fall (SC-9.5-1). A single loser dies; when two lose together the player picks and a die decides (4-6 grants the pick) (SC-9.5-4, SC-9.5-5). After round one the party may retreat by any exit, and if that way dead-ends it is bounced back (SC-9.5-6, SC-9.5-7); a successful retreat abandons the chamber, which stays permanently hostile (SC-9.5-8). A fight ends when every stranger is dead (victory → pickup/explore) or the whole party falls (SC-9.5-9). Victory has one more consolation: the survivors sweep their fallen comrades' *carried* items into the post-win pickup — so a slain member's artifacts, even the Eye on a corpse (§489), are no longer silently lost — while a wiped party's fallen leave theirs parked on the tile for whoever comes next; a *borne* Sword, Staff or Ring is lost with the body either way (SC-9.5-11). Only two death paths escape this rule: the Viper Pit swallows everything with its victim, and a retreat abandons all of the perished's artifacts, borne or not (§426).

## §10 Special areas

The cave holds five specially-marked areas, distinguished by a numeric special-type in the card encoding (SC-10-1): the Gateway, the Deep Pool, the Viper Pit, the Tomb of Kings, and the Great Hall. When the party first turns over a Pool or Pit card it steps only onto the near edge, and the crossing is deferred to the following turn — and only if it leaves through a *different* doorway than it entered (SC-10-3, SC-10-4). Retracing is always safe.

Crossing the **Viper Pit** is resolved one member at a time: each rolls a d6, and a 1 or 2 is fatal (SC-10.1-1, SC-10.1-2). A fallen member's treasure is lost to the pit, and losing the Eye of God's bearer there curses the party (SC-10.1-3, SC-10.1-4). The one safe passage is the Charmed Flute — a member able to play it lulls the vipers so the whole party crosses with no rolls (SC-10.1-5). Crossing the **Deep Pool** tests whether the party can carry its wealth through deep water: a living Giant shoulders it all, but without one every member must abandon its heavy metals to the pool, keeping only weightless artifacts (SC-10.2-1 … SC-10.2-3). Treasure sunk in the pool is *recoverable only by a Giant* (§Deep Pool): a returning party reclaims it only when a living Giant has the spare capacity to fish it out, and even then the recovery is a Giant-only, weight-limited pickup — whatever the Giants can't carry sinks straight back into the pool for a later visit (SC-10.2-4, SC-10.2-6). The **Tomb of Kings** and **Great Hall** are ordinary chambers with no crossing, distinguished only by richer draws (SC-10.3-1, SC-10.3-2). Finally, any chamber can become **pacified** — a per-party free-traversal state after three indifferent tests or a womanless Unicorn's guardianship — walked through freely, its treasure guarded, but still open to attack (SC-10.4-1 … SC-10.4-5).

## §11 Artifacts & treasure effects

**Passive combat artifacts** change a fight's arithmetic without any action: the Magic Sword sharpens a human-shaped fighter and lets a sword-bearer face a Spectre (SC-11-1, SC-11-2); the Magic Staff deepens a caster's power (SC-11-20); the Ring blesses every party die with +1 and, from level four, makes its bearer immune to a killing roll (SC-11-24, SC-11-25) — and every one of these magics is snuffed out by the Eye of God. **Consumable aids:** the Strength Potion is a single +2 surge that alone survives the Eye (SC-11-18, SC-11-19), and Lotus Dust sends a single stranger to sleep, though a Spectre resists and the Sorcerer is merely weakened (SC-11-9 … SC-11-12) — and, thrown in the pre-hazard pause, it works on Medusa herself, holding her under for two turns (SC-7.2-14, SC-11-42).

**Restorative artifacts:** the Healing Balm revives a fallen comrade at rest or during looting (SC-11-14, SC-11-15), and the Magic Staff doubles as a Wizard's wand of reanimation for a companion turned to stone in the current chamber, freeing them automatically on return (SC-11-21, SC-11-22). **Ward artifacts:** the Talisman turns Ghouls away at any depth and drives off Spectres from level four down (SC-11-16, SC-11-17). **Movement & discovery:** the Magic Carpet answers only to a Priest or Wizard and whisks the whole party one tile in any direction save out of the cave, a one-flight relic (SC-11-4 … SC-11-7); the Charmed Flute lulls Dragons and vipers while held and reveals concealed stairways when played (SC-11-29 … SC-11-33).

**Perilous treasures:** the Lost Ruby is guarded by a strength-8 statue that strikes only the one who reaches for it (SC-11-26, SC-11-27), and the Treasure Chest is a 100-kg gamble opened on a die — sand, riches, a curse, or a Spectre (SC-11-40, SC-11-41). Both are undone by the **Eye of God**, the campaign's double-edged relic: while borne it darkens all party magic yet annihilates Spectres, stills the statue, and clips even the Sorcerer (SC-11-34 … SC-11-37). Its price is loyalty — forsake it by dropping, handing off, or dying with it, and the party is cursed, one curse per abandonment (SC-11-38, SC-11-39).

## §12 Scoring & game over

Scoring happens only at game-over and is derived purely from the final state by `scoreGame` (SC-12-1). Every surviving member — status ORIGINAL or ALLY — contributes its creature's point value plus the points of every treasure it carries out; stone and dead members score nothing (SC-12-2, SC-12-3, SC-12-5). A member who has slain a Dragon doubles its own creature points, never its treasure (SC-12-4). Three party-wide adjustments follow: +30 for slaying the Sorcerer (SC-12-7), banked Treasure-Chest loot (SC-12-8), and a **flat 30-point** deduction for being under any curse — not 30 per curse — which is lifted entirely if the Sorcerer is killed (SC-12-9, SC-12-10). The raw total is clamped so it can never go below zero (SC-12-12).

The game ends in exactly three ways: a party escapes (`GS_ESCAPED`) only by invoking `exitCave` on a level-1 area with an up-stair (SC-12-16); it may abandon at any time (`GS_QUIT`, SC-12-17); or it is wiped when the last living member is lost (`GS_DEAD`, SC-12-18). A wiped party scores exactly zero regardless of loot (SC-12-13). Once any terminal state is reached the reducer refuses all further actions (SC-12-19). Although the engine computes a positive breakdown for an escaped or even an abandoned party, only an escaped party's score is treated as recordable by the surrounding UI (SC-12-20).

## §MP Multiplayer

A multiplayer game is one **shared Cave** explored by up to four **parties**, one per seat (SC-MP-1). The Cave — the map of placed cards, both decks with their indices, and the seed — is common to everyone (SC-MP-2); everything else (roster, position, phase, score, curses, active fight, pacified chambers) is private to one seat (SC-MP-3). The engine never forks its rules: a seat's action composes a temporary single-party view, runs the ordinary `reduce`, then splits the result apart (SC-MP-1, SC-MP-15). Play order is decided at random at build time, and the pick order is that reversed — first to draft is last to move (SC-MP-6, SC-MP-7). Selection is a turn-based draft from the one shared creature pack, so a card another seat took is unavailable (SC-MP-9, SC-MP-10). In play, `mpReduce` is strictly turn-gated (SC-MP-13); a seat's move touches only its own party plus the shared cave (SC-MP-16). The turn passes when a party returns to rest, leaves play, or completes one round of a fight — because a battle is fought one round per turn, other parties acting between rounds (SC-MP-18). Turn advance skips terminal parties, and once none are exploring the game is finished (SC-MP-20). Under this beginner ruleset `mpReduce` still accepts no inter-party action, and the engine tracks each party's score and kills but does not itself compute a winner (SC-MP-23, SC-MP-24).

The M2 *awareness* layer is the read-only groundwork (plan WS-1) for the inter-party rules of spec I-5..I-14: `occupants` reports who else is standing in a chamber, and `areaInteractionMask` says whether a PvP attack could legally be declared there — never across the Viper Pit or the Deep Pool, never while strangers remain in the chamber, and never while a co-located party is mid-fight with strangers (SC-MP-25, SC-MP-26). `pvpSurprise` grants the attacker's +1 only when it is not following the defender in — the two parties entered by different ways (SC-MP-27). None of this adds an `MpAction`; the Convex `playView` merely surfaces the awareness to clients as `hereSeats` + `areaMask` (out of engine scope).

**Sessions & windows (M3).** The interaction layer runs *beside* the turn order: trades, door-sharing, PvP and union actions are routed before the turn gate, so a session's counterpart answers off-turn inside a clock window the engine never reads itself (`now`/`windowMs` are plain parameters). A trade is a propose → basket → double-confirm handshake that commits ATOMICALLY — any failure (item gone, over capacity) clears both confirms and moves nothing, and the Eye of God passed in a completed trade carries no curse (SC-MP-28). Secret doors are per-seat knowledge: a mirrored stair is invisible (the move blocked) until the seat has learnt its coords by traversal, by witnessing a co-located rival use it, by an explicit `showSecretDoor`, or by the Charmed Flute (SC-MP-29).

**PvP (M4).** A fight between parties opens with the declaration — legality from the area mask, surprise from the doorway rule, and the §388 heavy-treasure drop onto the tile for BOTH sides — then a staged layout: the defender lines up (casters behind only with the numbers), the attacker engages (1v1/1v2/2v1, never 2v2, must engage all), the defender assigns casters last and the round resolves with the *solo* combat arithmetic, slaying the strongest of the losing group (Ring bearers spared) and spilling the fallen's items for the eventual victor (SC-MP-30). A wiped command goes terminal on the spot; otherwise ownership alternates round by round. Retreat leaves the drops behind and earns a two-turn flee grace, consumed on clean-flight rules; a mutual stop hands each side back its own drops; a stalled stage auto-defaults rather than dead-stop (SC-MP-30, SC-MP-31).

**Unions (M5).** United parties march as one under the LOAN model: subordinates' living members physically move into the commander's array, each carrying an `mpTag` identity tag — and because solo rules like Mutiny splice that array, every commander action ends with `reindexUnion` re-deriving loan and recruit positions from the tags (the mutiny regression) (SC-MP-32). Joining costs a one-turn forfeit; subordinates never play a solo turn; the commander's PvP layout must honour strongest-fights-strongest; recruits are allocated by handshake on dissolution (a disagreement parks them neutral); a rear-guard detachment deters rivals' pickup (defence fights are a documented TODO); and a shared Sorcerer kill splits the 30-point bounty ⌊30/n⌋ per seat (SC-MP-33). Under the extension kit, ANY seat's Sorcerer kill — a union command's or an ordinary solo party's, union-agnostic by design (the same "one Sorcerer, cave-wide consequence" precedent as the zombies variant's annihilation sweep, SC-MP-37) — is cave-global for the Apprentice: since there is only one Sorcerer, his death breaks EVERY Apprentice ally's loyalty everywhere in the cave, reusing the solo revert across every seat's party and, for one currently on loan, ending the loan and re-indexing every affected union in the same stroke (SC-EXT-31).

**Concurrency & RNG (M6).** Every seat rolls its own dice: `buildMpGame` derives a per-seat `diceSeed` substream from the game seed (derived, never consumed), PvP rounds roll from each side's command lead, and the shared cave stream is never perturbed by an inter-party fight (SC-MP-34). With the per-game `concurrent` flag on, the turn gate drops entirely — free roam, deck draws serialised by arrival, sessions locking their participants, a rival's live stranger-fight barring entry, the flee grace degrading to a pursuit lockout, and forfeits paid down by rival activity; off, play is byte-identical strict round-robin (SC-MP-35).

**Variants (M7; extensionKit added M8).** `variants` is fixed at build time. Fog-lite masks everything a seat has not stood on to face-down stubs via each party's always-recorded `seenAreas` ledger (SC-MP-36). Zombies turns a wiped seat into a spoiler: after a one-turn forfeit its corpses rise — barred from loot, stranger contact, water and (Sorcererless) secret stairs, hazard-immune by post-action repair, unionable only with other zombies, casting nothing in PvP — until any seat's Sorcerer kill annihilates the risen for good (SC-MP-37). `extensionKit` opts the whole game into the extension kit (§EXT): `buildMpGame` widens the ONE shared large/small pack to 90/101 cards, and `compose` mirrors the flag onto every composed seat's `GameState.variants` so solo kit rules see it exactly as a solo kit-on game would (SC-EXT-30) — pure deck/plumbing threading, no multiplayer rule of its own. With BOTH variants live, the kit's own hazards split (SC-EXT-33, task 4, a design-Part-4 proposal pending MSW's confirmation): Desertion and Quarrel — the party turning on itself — are politics the dead have none of, so both are repaired away exactly like Medusa/Ghouls; a Crypt fall and Harpies' theft are ordinary hazards to the dead, applying untouched; the kit's five other specials are ordinary chambers needing no gate of their own.

**Shared kit content across seats (M8, SC-EXT-32).** With the kit on, several solo mechanics leave a mark on the ONE shared cave that a later seat — not just the one who triggered them — can run into. A Harpies stash (SC-EXT-12) and a Demon's relocation (SC-EXT-21) both park an ordinary content code on a shared tile, so any seat that later walks onto it inherits the consequence: loot to recover, or an ambush to face. Gallery statues (SC-EXT-10) persist the same way, and a Staff-Wizard seat wakes a statue a different, Staff-less seat left behind — the resulting reaction test rolls on the ONE shared cave stream, exactly like any other solo-composed roll (the per-seat `diceSeed` split is reserved for the MULTI layer's own dice, PvP only). A Whirlpool drag and the Well's no-withdraw turn are the mirror image: both are purely per-seat (`compose` only ever touches the acting seat's own fields), so a co-located seat is untouched by either — while the Bell Rope's one-pull-per-tile-ever spend (`AF_BELL_SPENT`) lives on the shared area itself, blocking every seat once any one of them has pulled it. The Crypt is the one mechanic that needed help: solo's `cryptCoord` carries no content-code footprint at all, so naive composition made it invisible to every seat but the one who parked it. `CaveState.cryptCoord` closes that gap — `compose` always seeds a party's `cryptCoord` from the cave's own copy, never the party's potentially-stale own, and every action resyncs the cave's copy from what that seat's composed result just produced — so the Crypt, too, is cave-shared: whichever seat is first to actually call `enterCrypt` takes it, and it spends cave-wide, for good.

## §EXT Extension kit

The extension kit is an opt-in variant, off by default: `newGame(seed, picks, variants)` stores `{ extensionKit?: boolean }` immutably for the life of the game, and every deck builder accepts the same optional parameter — absent, `{}`, or `{extensionKit:false}` is byte-identical to calling with no variants argument at all (SC-EXT-1). Turning it on never rewrites a base rule; it only changes what the decks contain and how wide the `special` field is.

The kit's new ids append strictly after the existing ranges — creatures 14-20, treasures 15-21, hazards 5-8 — but they live in tables of their own (`KIT_CREATURES`, `KIT_TREASURES`, `KIT_HAZARD_NAMES`) rather than growing `CREATURES`/`TREASURES`/`HAZARD_NAMES` in place, so those base tables keep the exact shape pinned since Milestone A; `ALL_CREATURES`/`ALL_TREASURES`/`ALL_HAZARD_NAMES` concatenate base and kit for anything that needs to resolve either by id. Two small variant-aware helpers, `selectionCost` and `startingStock`, fold in the kit-on-only party-selection data — Ogre 5→4 and Troll 4→3, Witch/Scholar/Thief/Lion/Wolf joining the selectable pool, Woman/Dwarf stock rising 3→4 — as pure lookups the base game doesn't call yet (SC-EXT-2).

The area-card `special` field widens from 3 bits to 4 (mask `& 7` → `& 15`) to make room for six new special-area codes (6-11: Chasm, Bell Rope, Lair, Whirlpool, Gallery, Well). Because no base tile's encoded value reaches the newly-freed bit, every one of the 61 base `AREA_CARDS` decodes identically under the wider mask, and the kit's 30 `EXT_AREA_CARDS` tiles use that same bitfield (SC-EXT-3). Finally, the deck builders are deck-as-gate: with the kit off, `buildLargePack`/`buildSmallPack` shuffle exactly the same 60/71-card templates as before this milestone; with it on, the 30 extension tiles and 30 extension small-pack codes are concatenated onto the template BEFORE the shuffle, producing a 90-card area deck and a 101-card small pack for that game only (SC-EXT-4).

Four of the six new special areas have engine rules so far. The **Chasm** is a one-way escape hatch: `descendChasm` is legal in explore OR encounter phase alike, needs no roll, and parks any pending strangers/treasure back onto the tile before dropping the party a level via `relocateDown` — a fresh card, no mirrored stair-up, `fellThroughTrap` barring `withdraw` at the landing, and the Chasm itself stays usable on every later visit (SC-EXT-5). The **Whirlpool** behaves like an ordinary chamber on entry (unlike Deep Pool/Viper Pit it draws normally, and it emits an `enteredSpecial` warning telegraph every time), but crossing its shallows — leaving by any doorway but the one the party came in by — rolls a d6: 1-2 cancels the lateral move already applied — including popping any brand-new tile it placed and giving back the large-pack card it drew, so a cancelled crossing leaves no phantom tile on the map and costs no extra card beyond `relocateDown`'s own draw — and drags the whole party one level down instead, from the Whirlpool's own tile, with the same one-way `relocateDown`/`fellThroughTrap` semantics as the Chasm; 3-6 leaves the crossing unaffected. Retracing the entry doorway never rolls, and every fresh crossing rolls again — there is no once-per-game flag (SC-EXT-6).

The **Well** and the **Bell Rope** both draw extra small cards INTO the chamber the party is already standing in, rather than moving anyone — so they share one resolution tail, `resolveExtraDraw`, that mirrors the per-chamber body of a fresh entry (a drawn Spectre still meets the Eye/Talisman, a drawn Medusa can still open the pause, hazards fire in the usual order — a drawn Trap still drops the party a level, a drawn Medusa still gazes — and the phase settles the normal way) without ever counting as a "fresh entry" for SURPRISE purposes: the draw itself earns none, but — this is a deliberate SC-4-16 fix, not the original behaviour — it must also never CLOBBER surprise already earned by the chamber's original fresh entry and not yet consumed, so `resolveExtraDraw` captures `surpriseReady` beforehand and restores it afterward whenever the party is still in `encounter` (a drawn Trap's fresh landing area computes its own surprise correctly and is left alone). A drawn Dragon's Charmed-Flute lull still announces itself even though the chamber isn't newly entered, since the dragon is nonetheless new information to the player. This whole contract — captured as `finishExtraDraw`, shared by both callers below — covers the draw whether it resolves immediately OR pauses first: a drawn Medusa with Lotus Dust held opens the SAME pre-hazard pause a fresh entry would, but tags it `medusaPause.extraDraw` (carrying the captured `surpriseReady` along) rather than a plain `{freshEntry:false}`, so `resumeFromMedusaPause` routes `proceed` or the Lotus throw through `finishExtraDraw` too — otherwise the pause would silently reopen the same clobber/suppression the direct path fixes. `drawFromWell` pulls exactly one code and is legal every turn spent at the Well, in explore or encounter alike, with no spent flag — only a non-empty small pack gates it (SC-EXT-7). `pullBellRope(mi)` names a living member to pull, and is legal only ONCE per Bell Rope tile ever, whatever the roll: a visible d6 bands into vanish (a roll of 1 — the puller is removed from the game outright, with everything carried, borne or merely carried alike — never spilled to the floor — Desertion semantics: not dead, not revivable, and a total-wipe check in case they were the last), toll (2-3 — foreboding narration only), and stir (4-6 — two codes drawn and resolved exactly like the Well's draw) (SC-EXT-8). Both a Well draw and a Bell Rope "stir" set a new `noWithdrawTurn` flag, giving `withdraw` a third blocking condition alongside `fellThroughTrap` and a collapsed `prev`: since `turn` only advances on `move`, the block applies for exactly the turn it fired on and needs no explicit reset (SC-EXT-9).

The **Gallery** petrifies its own strangers on the draw: every creature drawn there while the chamber is being freshly populated from the small pack arrives as a scenery statue rather than a live stranger — no reaction test, no threat, and any treasure alongside it is free for the taking — except the Sorcerer, Spectre, and Demon, who arrive exactly as they would anywhere else. This petrify-on-arrival transform is carefully scoped to a genuinely FRESH draw only: reloading a code already parked on the tile from an earlier visit (whether it's an untouched statue or an ordinary stranger the Staff woke last time) never re-runs the check, so nothing already established as a stranger is ever turned back to stone by a later visit. A living Wizard bearing the Magic Staff — the same bearer test that already averts Medusa's gaze and frees stoned party members — cracks every statue in the room awake the instant the party steps in, whether that's the very first visit or a much later one: they become ordinary strangers and the room plays out as a standard encounter, one group reaction test covering them all, not a test apiece (SC-EXT-10/SC-EXT-11). This new "statues" bucket is deliberately NOT reset unconditionally the way `sleeping`/`lulled` are — only a genuine Gallery entry touches it — because a base game or a kit game that never visits a Gallery must never grow the field at all, preserving the frozen solo-golden snapshots byte for byte.

The **Lair** is unremarkable as a chamber — no draw modifier of its own — but it is the one permanent address the Harpies' stolen hoard (a later kit task) can be delivered to. The moment its tile is placed on the map AND entered, its coordinate is remembered for the rest of the game; if anything was stolen before the Lair turned up, it spills onto the Lair's own floor right then, as ordinary floor treasure. Once the Lair's coordinate is known, any later theft lands there directly instead of queuing — the queue only ever exists for the gap between a theft and the Lair's own discovery (SC-EXT-12).

The **Crypt** is not a special tile at all — it is Crypt/Gems, an ordinary treasure card (id 21, heavy, 25 kg, 20 pts) that can turn up in any chamber's small-pack draw. Drawing it doesn't drop it on the floor: it parks, remembered as a single coordinate (`cryptCoord`, the same shape as the Lair's own `lairCoord`) rather than anything living in the chamber's working set, since the kit's small pack holds exactly one such card — and the parking is announced, not silent, with the design's own on-screen line, fired exactly once by whichever draw (a fresh chamber entry, or a Well/Bell extra draw finding it) actually sets `cryptCoord`. From then on, at rest in that chamber (any later turn, not only the one it was found on) a new `enterCrypt` action is on offer — gated tighter than the Chasm/Well/Bell Rope's "works mid-encounter too" latitude, since the design never extends that latitude to the Crypt. One d6 decides it for good: 1-2 is an inescapable trap that drops the whole party a level exactly like any other one-way fall — a Dwarf's usual trap-guiding talent simply doesn't apply here, because this path never goes near the hazard machinery a Dwarf wards off — while 3-6 turns the parked card into the gems themselves, ordinary floor treasure 21 waiting on a normal, weight-gated pickup. Either roll spends the crypt for good; there is no second entry. Making that 25 kg pickup (and its 20 points) actually work end to end meant widening base-game treasure lookups from the base-only table to the combined base+kit one in four places: carry capacity and scoring (`pickup.ts`, `score.ts`), and the two heavy-treasure-drop sites that force a fighter to set down heavy loot before a round — the ordinary fight plan and a PvP declaration, plus the same pattern already shared with Ghouls — all invisible to a kit-off game, which can never hold an id past 14 to trigger the difference (SC-EXT-13).

**Desertion** is a hazard, not a special area, and slots into the existing hazard machinery exactly where Mutiny does — except it fires every ally's own d6, one at a time down the roster, rather than a single verdict for the group. Original party members are never at risk; only allies roll, and a Wolf ally shrugs off the die entirely, called out by name so its immunity reads as a deliberate trait rather than an oversight. A failed roll (1-2) is final and total: the deserter and everything they own — worn, wielded, or merely carried — leave the story outright, not merely the party, and the roll itself carries a snapshot of exactly what that was, so the presentation layer can name it rather than gesture at "everything". A clean sweep of safe rolls earns the party a quiet, dedicated line of reassurance, assembled by the presentation layer from the same per-ally rolls (and Wolf skips) it already has, rather than a whole extra engine event just to say nothing happened — including the edge case of a roster that is nothing BUT Wolves, which rolls no dice at all yet still deserves that same reassurance (SC-EXT-14).

**Harpies** is a hazard with a defence built in: if the party carries nothing worth stealing — no artifacts at all — or carries the one artifact that specifically wards them off (the Talisman), the card simply lurks, exactly as Medusa and Ghouls do, re-checking the same condition on every later visit. Otherwise it strikes in full: every artifact any living member holds, whether merely carried or actively borne (a Sword, a Staff, a Ring), is gone at once, gathered up and delivered to the one place Harpies ever keep loot — the Lair, directly onto its floor if the party has already found it, or into a holding pile that spills out the moment the Lair turns up (§EXT the Lair). Losing the Eye of God this way is no different from losing it to death: the curse it leaves behind still falls, though the game says so in its own words this time, "the Eye of God is torn away," not the bearer-death line reused wholesale. A Harpies card that actually strikes is spent for good; only a card that merely circled off, empty-handed or warded, comes back to try again (SC-EXT-15).

**Quarrel** turns the party on itself for exactly one round. Two members — the two who would hit hardest in an ordinary fight, by the same strength-plus-magic-plus-artifacts total the fight resolver already uses — square off, with the placid, the Wolf and the Lion, sitting it out no matter how strong they are. Each rolls a die against the other, the party's usual blessings and curses applied evenly to both sides (which cancels out in who wins, but is the honest way to compute a roll the party is making against itself), and the loser goes down exactly as if a stranger's blow had done it: a fair fight, revivable by the Balm, the whole business narrated in one breath rather than echoed twice. If tempers flare with nobody eligible to throw a punch — everyone remaining is a Wolf, a Lion, or simply not there — nothing happens, and the game says so plainly rather than pretending a duel took place. Either way the hand plays on as normal the moment the dust settles (SC-EXT-16).

**Spell** reaches backward rather than forward: it undoes the very passage the party just walked through, but only if that passage was an ordinary tunnel, not a chamber, not the Gateway, and not already rubble. The old tunnel's identity doesn't vanish — it slides back into the deck to be drawn again someday — and a fresh card takes its place on the map, sealed and unknown until the party actually walks onto it a second time, at which point it plays out exactly like any other new discovery: a chamber to draw into, a stairway that mirrors itself if it needs to, nothing special about the mechanism at all. Everything the old tile remembered about how it connected — a secret door, a stitched-together stair — is erased along with it. When there's nothing eligible behind the party, or the deck itself has run dry, the spell simply fizzles, and nothing on the map so much as flickers (SC-EXT-28).

Five new creatures round out the kit, and three of them borrow their artifact manners wholesale from a base class rather than getting rules of their own: the Apprentice handles the Carpet, the Balm and the Magic Staff exactly as a Wizard would — including averting Medusa's gaze and cracking a Gallery's statues awake — the Scholar and the Witch do the same for everything a Priest may touch (though never the Staff's reanimating trick, which stays a Wizard's alone), and the Thief inherits a Man's turn with the Charmed Flute. None of this touches the Sword's or the Staff's own per-species combat bonus, which still names only the handful of creatures printed on the card. The Lion and the Wolf carry nothing of anyone's and appear in no artifact's list at all; between them and the newly-eligible three, virtually every creature a party might now recruit needed the engine's stranger/ally lookups widened from the base sixteen-creature table to the full base-plus-kit one, since a Witch or a Wolf reacting to on sight, fighting, or simply being scored at the end of the game had never been exercised before and would otherwise crash on the very first attempt (SC-EXT-17).

The Apprentice's loyalty is a bet on the Sorcerer's life. Her reaction test carries one custom band the rest of the cave never needs: while he lives, a roll of six wins her over and nothing else does — no indifferent middle ground, hostile the rest of the way; the moment he falls, that same six reads hostile too, so recruiting her at all is a wager that pays out only for as long as the campaign's other great prize stays unclaimed. Should the party actually collect that prize, her allegiance breaks in the same instant the killing blow lands: she reverts to a hostile stranger standing right there in the party's own area — mid-fight, if that is when it happens — taking nothing with her; whatever she carried spills to the floor exactly as a Mutiny deserter's would. She is worth nothing at the final count regardless, because she is bound to the cave itself: even a clean escape leaves her behind, quietly subtracted from the party that walks out without her (SC-EXT-20).

The Demon does not wait to be found — it arrives already behind you. Drawn from the small pack, it never takes a seat among a chamber's ordinary strangers; instead it steps into whichever area the party has just left, lurking there until they either return to it or are driven back into it retreating from something else. There is no reaction test to talk it down — entering its ground is simply a fight, sprung the instant the party arrives. Only magic reaches it: a caster's power bites as it would against a Spectre, and so, uniquely, does the Magic Axe in any hand at all, no matter whose. A party with neither loses the exchange outright, the strongest among them cut down before a blow is even considered, the same fate a friendless Spectre metes out. The one tile the Demon cannot claim is one already gone: rubble left by an earlier earthquake gives it nothing to stand on, and it simply fails to arrive at all. It lurks just as well on a Deep Pool or Viper Pit tile as on an ordinary tunnel or chamber — those two special areas have their own entry logic that runs before a chamber ever would, so the ambush is checked there too, ahead of anything else that tile does on arrival. Nor does an area's standing truce spare you: a chamber the party has already talked its way past — pacified by indifference, its strangers left parked and harmless — offers the Demon no cover either, since it is never indifferent to begin with; walk back in on one lurking there and it springs exactly as it would anywhere else, instead of being quietly swept back onto the floor with the rest of that chamber's settled peace. Win the fight and there is no mistaking it for an ordinary kill: the Demon collapses into ash, its own line rather than the party's usual "foes down" tally (SC-EXT-21).

The Wolf, already excluded from Quarrel's duel and immune to Desertion's roll, is immune to two more of the cave's cruelties: Medusa's gaze passes over it without so much as a die thrown, and a Mutiny that would otherwise scatter every ally leaves a Wolf standing fast — cheap muscle that simply will not be talked, charmed, or frightened away (SC-EXT-18).

The Thief earns his keep by a different door than combat: standing guard beside a chamber the party has worn down to permanent indifference, he can slip past watchers who have stopped caring enough to fight over their hoard, and the treasure they still technically guard opens up to the whole party's ordinary pickup, no blade drawn (SC-EXT-19).

The **Elixir** is a gamble any creature in the party may take, and — unlike most artifacts, which wait for a fight or a quiet moment at rest — it may be drunk almost anywhere, the one exception being mid-fight itself. One draught, one die: a roll of one is poison, and the drinker goes down exactly as any other killing blow would take them (the Ring's usual protection still applies; a fatal draught's curse and its spilled belongings are checked in the same careful order every other death in the cave already uses, so nothing is lost to a rearranged check). A roll of two or three is nothing at all — pond water, a wasted risk. But a roll of four through six settles something permanent into the drinker's bones: two points of fighting strength that never fade, riding on them through every fight for the rest of the game, visible alongside the Sword's and the Potion's own bonuses whenever they take the field. Whatever the draught does, it is spent — there is no second dose from the same bottle (SC-EXT-22).

The **Idol** keeps its secret until the very end. It is heavy — twenty-five kilograms of stone, exactly as demanding of a party's strength as a haul of Silver or Gold — and beyond hauling it out of the cave, it does nothing at all: no use, no passive gift, nothing to spend it on along the way. Only at the final reckoning does it speak: a die is cast for it there, once, and its worth is ten times whatever that die shows — as little as ten points, as much as sixty. That roll is no ordinary dice tumble, though; it is drawn from the exact seed the game ends on, so asking the same finished game to settle its score twice always gives the same answer, and a replay of that game always uncovers the identical treasure. Carried out by the dead or the stone-turned, it is worth nothing, same as any other loot they never really got to keep (SC-EXT-23).

**Holy Water** is a single vial with four different uses, and the party only ever gets to choose one. Point it at a comrade turned to stone and the stone simply sloughs away — no Wizard, no Magic Staff, just the water doing what it does. Point it at a Gallery's silent statue instead and the same crack spreads through different stone: that one creature wakes on the spot, exactly as if it had just been drawn into an ordinary chamber, reaction die and all. Point it at Medusa's own lingering presence in a room and there's no reaction, no roll at all — she simply stops being a threat there, forever, the next visit and every visit after. And point it at the cave's two great magical menaces — the Sorcerer himself, or his apprentice — and nothing dies at all; the water merely saps them, two points of magical power gone for the rest of the game, an injury that adds cleanly onto whatever Lotus Dust or the Eye of God have already done to them. Whichever the party chooses, the vial is spent — one water, one miracle, never a second (SC-EXT-24).

The **Scroll** is a blunt instrument dressed as a prayer. Read aloud by any human hand — nobody has to be chosen, the party simply needs one — its words scour every mundane creature in the room to nothing, an unglamorous end that earns no glory and no points, only an empty space where a foe used to stand. Anything touched by real magic shrugs the words off entirely and stands there laughing while its comrades crumble; if a fight was already under way, it simply continues against whoever's left. But scripture like that always asks a price: reading it settles a curse on the party, the same curse that dogs every other unlucky choice in the cave, and it does not lift until the Sorcerer himself falls (SC-EXT-25).

The **Magic Axe** and the **Magic Shield** both borrow the Magic Sword's own shape — an item worn or wielded rather than merely carried, which stays with a body turned to stone or slain rather than spilling free — but part ways from there. The Axe is a second strength-granting blade in every sense but name: Man, Woman, Hero and W-Hero draw a flat point of extra fighting strength from it, and a Dwarf — otherwise the cave's frailest fighter — draws three, suddenly making the kit's extra Dwarf card worth fielding. Every OTHER bearer still carries it faithfully, gaining nothing in strength but keeping the one thing that matters against a Demon: in ANY hand at all, Axe or no bonus, it lets its bearer stand against that creature the way only real magic otherwise can. The Eye of God silences the strength bonus exactly as it silences the Sword's own (SC-EXT-26).

The Shield asks nothing of who carries it — truly anyone may sling it, hand it off, or leave it on the floor — but it only wakes up, warding, in the hands of the same four classes the Sword favours; in anyone else's grip it is inert baggage. When it IS awake, its ward is narrow by design: it doesn't blanket the whole party's fight, only the one foe standing directly across from its bearer. An ordinary opponent's magic is turned aside entirely; the Sorcerer or his Apprentice, tougher customers, merely have their power dimmed by two — on top of whatever Lotus Dust or Holy Water had already done to them, never below nothing. A foe facing a different member of the party altogether never feels it at all. Like every artefact's magic, an active Eye of God switches the Shield off outright (SC-EXT-27).

Kit-on party selection folds into the same 6-point budget and stock rules the base game already enforces (§3/§5): the Witch, Scholar, Thief, Lion and Wolf simply join the selectable roster at their own listed cost, the Ogre and Troll ship a point cheaper than their base-game price, and the kit's extra Woman and Dwarf cards raise those two creatures' stock by one each — the Apprentice and the Demon are never selectable, kit-on or off, appearing only as cave inhabitants. Turning the kit off restores every one of these numbers exactly, so a kit-off `validatePicks` call is byte-identical to the game before this milestone (SC-EXT-29).

## A.5 The RNG algorithm (`rng.ts`) — for faithful ports

```
A = 1103515245, C = 12345, M = 2^31
nextSeed(s)      = (s*A + C) mod M          # 62-bit product; only the low 31 bits matter (M = 2^31)
bits(s')         = floor(s' / 32768) mod 65536   # upper bits 15..30
rollDie(s)       -> s' = nextSeed(s); value = min(5, floor(bits(s')/10923)) + 1   # 1..6
randBelow(s, n)  -> n<=0 ? {s,0} : (s'=nextSeed(s); {s', bits(s') mod n})
shuffle(s, arr)  -> Fisher–Yates, i = len-1 .. 1, j = randBelow(i+1), swap; returns {advanced seed, new array}
```

> Port note: because `M = 2^31` is a power of two, only the low 31 bits of the product are needed — a 32-bit truncating unsigned multiply masked with `& 0x7FFFFFFF` reproduces `nextSeed` exactly; 64-bit math is not required.

# Appendix B — Corrections vs the v1 design-spec

The v1 `design-spec.html` predates most of the artifact, hazard, combat, and multiplayer work; its §15 "Gap Analysis" and §16 "Implementation Sketches for the Open Gaps" are almost entirely obsolete. Key corrections (code is authoritative):

**Data model (§3/§5):** the small pack is **71 cards** (one finite deck shared between party selection and chamber draws), not the old two-pool 52-card model; hazards ship **two Earthquakes** (not one); area-card index 41 is **42 (EWU)**, not 74; the seed is a **caller-supplied parameter**, not clock-derived.

**Turn model (§2.2/§4):** the engine is a **pure phase-machine reducer** (`reduce(state, action) → {state, events}`), not the old blocking keystroke loop; the five `phase` values and the full 16-action / 47-event catalogs are the real boundary and were absent from v1.

**Movement (§6):** earthquake-rubble impassability, ascent secret doors + numbered markers, the **never-rotate** tile rule, and length-driven pack-exhaustion are all real and were missing/incorrect in v1.

**Encounters (§8):** the human reaction tables are **real** (Hero 3/3, Priest 1/4, Man/Woman 2/4, Dwarf 0/4 — not em-dash); the **Dragon is 4/6** (1–4 hostile), not always-hostile; Attack is **+1 only on a fresh entry** (not unconditional); Withdraw is **not always available**; the womanless-Unicorn guard, Charmed-Flute Dragon lull, and pacified-chamber Attack are all implemented.

**Fights (§9):** combat is a **submitted battle plan** with a full validation set (two-vs-two ban, must-engage-all, gang-up, enemy-caster fold-in), not auto focus-fire; Ring invincibility, Strength Potion activation, casters-fight-at-total-strength, heavy-treasure drop, blocked-retreat, and the choose-a-casualty die are all implemented.

**Special areas (§10):** the Viper-Pit fatal threshold is **1 or 2**; Deep-Pool drops all heavy treasure to a single `dropped` list on the tile (no per-doorway model); flute-based pit-treasure recovery is **not** modelled.

**Artifacts (§11):** every "not implemented" in the v1 status table (Talisman, Healing Balm, Lotus Dust, Magic Carpet, Lost Ruby statue, Eye of God, Treasure Chest, Magic Staff reanimation) and every §16 sketch is now **shipped code**; the Lost-Ruby statue strikes **only the wrestler** (it does not stay aroused); the Eye curses on drop, transfer, **and** death.

**Scoring (§12):** the curse penalty is a **flat −30** (not −30 per curse) and is lifted entirely by slaying the Sorcerer; the formula now includes **`bonusScore`** (banked Chest loot); "no breakdown on quit" is a UI decision, not an engine rule (the engine only zeroes for `GS_DEAD`).

**Multiplayer (§MP):** entirely undocumented in v1 (which listed multiplayer as out of scope); now implemented in `multi.ts` as a shared-cave / per-seat-party model, with the M3–M7 interaction layer (trades, PvP, unions, concurrency, variants) in `multi-*.ts`. Deliberate omissions/simplifications in that layer (each documented at its module header): `refuseMove` is implemented as ≡ `leaveUnion` (refusing the commander's move IS leaving); rear-guard detachments deter absolutely — `hostileDetachmentAt` blocks a rival's pickup but no guard auto-defence fight is fought (TODO M6+); a disagreed recruit allocation parks the ally as an ordinary neutral stranger rather than awaiting the ensuing fight's victor; zombie corpse ABSORPTION and the one-turn re-animation of a PvP-slain zombie party are not modelled (no per-tile corpse model — a risen party slain again is terminal for good); and borne items rest with the flesh — they are LOST when a wiped party rises as zombies.

# Appendix D — Cross-implementation conformance vectors

`docs/specs/conformance/` holds fixed solo playthroughs rendered as plain 7-bit-ASCII text —
everything a **foreign implementation** (e.g. the VAX Macro-32 port) needs to prove it reproduces
this engine: the initial `seed`/`picks`, the ordered action log to drive its reducer, a
post-action checkpoint per move (turn / level / area / phase / gs / **RNG cursor**), and the full
end state (party, map, working sets, score). The RNG cursor is the sharpest diagnostic: any
divergence in roll count, order, or LCG arithmetic (A.5) shows on the exact line it occurs.

- **Format & action grammar:** `docs/specs/conformance/README.md`.
- **Generator & drift guard:** `conformance-vectors.test.ts` — the vectors are vitest file
  snapshots, so the suite FAILS if engine behaviour drifts from what is committed; regenerate
  deliberately with `pnpm --filter engine exec vitest run -u src/conformance-vectors.test.ts`
  in the same commit as the approved rules change (mirror of the solo-golden discipline).
- **Coverage:** twenty runs. Eight mirror `solo-golden.test.ts` (combat, pickup, hazards,
  deaths); eleven base-game TARGETED fixtures are found by seed sweep, driven by steered policies
  committed in the generator: an escape with a laden party (`-escape`), a Sorcerer kill
  (`-sorcerer`), four artifact runs (`-artifacts`) that together use every usable artifact (Carpet 4,
  Lotus 5, Balm 6, Potion 8, Staff 9, Flute 12) and exercise the Lost-Ruby wrestle and the Treasure
  Chest, and five gap-coverage runs (`-chest2`, `-ring`, `-reclaim`, `-medusaavert`, `-petrified` —
  the last also pins the medusa pause: `MDS` phase, the untargeted `USE 5` throw,
  `medusaSlept`/`medusaAsleep`). The twentieth (`-kit`, Task 17) is the extension kit's own vector —
  the ONE `KIT 1` (`variants.extensionKit: true`) run, seed 397/party 18,20, driven by a "kit" policy
  that ports `kit-golden.test.ts`'s own decision logic verbatim so the two fixtures replay the
  identical action sequence; it pins Chasm/Whirlpool/Well specials and a parked Crypt (SC-EXT-5/6/7/
  13), all four kit hazards (SC-EXT-14/15/16/28), two kit `USE`s — Holy Water and the Scroll
  (SC-EXT-24/25) — and kit-creature reaction groups, ending in a natural `GS 2` party wipe (not a
  step-cap truncation). They are conformance smoke tests; the normative contract remains Part I.
- **Porting workflow:** `docs/specs/PORTING-GUIDE.md` ties Part I/II, Appendix A, and these
  vectors into a step-by-step plan for a port.
