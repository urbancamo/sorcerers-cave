# The Sibyl Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the optional Sibyl card as a game variant (solo and multiplayer): she is met last and once, never fights, never leaves the cave, and lets her party take a free look at any face-down tile or the top of the large pack.

**Architecture:** The variant flag `variants.sibyl` adds one small-pack card (code 121, creature id 21). While in a chamber she sits in the existing parked-awake slot `state.lulled`, which every "leave the chamber" path already saves, so no fight, mutiny, scoring or exit code ever sees her. A reaction test fires only when no other stranger is left. Joining sets `state.hasSibyl` (a party flag, not a party member). A new free `examineArea` action reads the pack top or a face-down tile from state; the UI shows the result only to the looker. High scores gain a third key (`sibyl`), giving mode × kit × Sibyl = 8 tables.

**Tech Stack:** TypeScript, vitest, pnpm/turbo monorepo (`packages/engine`, `apps/web`), Convex backend, React.

**Spec:** `docs/superpowers/specs/2026-10-11-sibyl-design.md` (amended in this planning round, see "Deviations from the spec" below). Brief: `docs/requirements/2026-10-11-sibyl.md`.

## Deviations from the spec (decided while reading the code)

1. **She is a party flag, not a party member.** The spec had her join `state.party` with status 1 and carved her out of fights, `living` checks, mutiny and exit. About 30 call sites test `status === 0 || status === 1`; carving her out of each is large and fragile. Instead a friendly result sets `state.hasSibyl = true`. Every behavioural rule in the spec then holds by construction: she never fights or is wounded, never counts as a member (so she can never be the only one), mutiny and desertion cannot see her, she is not scored, and she stays behind because she is not in the roster. The visible behaviour is identical.
2. **She lives in `state.lulled` while in a chamber** (the slot used for flute-lulled Dragons). Every park site (`persistAndExplore`, `withdraw`, `retreat`, zombies) already saves `lulled` as `100 + id`, so no new parking code is needed.
3. **No `FLAG_SIBYL` creature flag.** Nothing reads one, so it is dropped (YAGNI).
4. **The look shows the tile as text** (exits, special, chamber/tunnel), not tile art. Tile art is a follow-up.

## Review Focus

Failure modes the spec implies but no single rule states, most likely to bite first. Each has a named test in the owning task.

1. **Other strangers in the chamber with her.** She must not be in the fight, and must be met after it is won (Task 3: "a fight never contains her", "met after the fight is won").
2. **Leaving mid-encounter.** `withdraw` must not lose her card (Task 3: "withdraw parks her in the chamber").
3. **Treasure in a chamber where she is the only stranger.** It is unguarded; pickup comes after her test (Task 3: "pickup follows her test").
4. **A pacified chamber whose only parked card is the Sibyl.** `attack` must not be offered, and attacking real guards must not drag her into the fight (Task 3).
5. **Multiplayer turn flow and privacy.** `examineArea` must not end the seat's turn, its event carries no card content, and the MP action validator must accept the `area` field (Tasks 4 and 5).
6. **Empty large pack / no face-down tiles.** No look is offered; a forged look is blocked (Task 4).

```ts
import { AF_DESTROYED, AF_UNRESOLVED, type GameState } from "./state";

/** The Sibyl's creature id and small-pack code (`100 + id`) — the optional variant card (SC-SIB-1). */
export const C_SIBYL = 21;
export const SIBYL_CODE = 100 + C_SIBYL;

/** The Sibyl stands in the chamber working set's parked-awake slot (`state.lulled`, shared with
 *  flute-lulled Dragons): every leave-the-chamber path already parks that slot as `100 + id`, so she
 *  rides along without any new parking code, and no fight/mutiny/scoring code ever sees her as a
 *  stranger (SC-SIB-2). */
export const sibylHere = (state: GameState): boolean => (state.lulled ?? []).includes(C_SIBYL);

/** She is ready to be met: here, not yet met by this party, and no other stranger is left to deal
 *  with first — she is tested "after other STRANGERS have been dealt with, and only once" (SC-SIB-4). */
export function sibylWaiting(state: GameState): boolean {
  return state.strangers.length === 0 && state.sibylMet !== true && sibylHere(state);
}

/** A parked content code that is a stranger guarding the chamber — any stranger but the Sibyl, who
 *  guards nothing ("She does not guard treasure found with her", SC-SIB-6). */
export const isGuardCode = (code: number): boolean => code >= 100 && code < 200 && code !== SIBYL_CODE;

/** Indices of placed tiles the Sibyl may show (SC-SIB-8): tiles lying face-down — dead-end cards laid
 *  unseen, and Spell-remapped tiles — that are not collapsed. */
export function examinableAreas(state: GameState): number[] {
  const out: number[] = [];
  state.areas.forEach((a, i) => {
    const faceDown = !a.faceUp || (a.flags & AF_UNRESOLVED) !== 0;
    if (faceDown && (a.flags & AF_DESTROYED) === 0) out.push(i);
  });
  return out;
}
```

/** Roll one reaction for the strongest stranger — or for `leaderId` when given (the Sibyl, SC-SIB-3) —
 *  honouring Test Mode's scripted outcome and forced die. Mutates `next` (advances `seed` on a real
 *  roll; consumes the one-shot Test Mode overrides). [Keep the original Test Mode / Next Roll Selector
 *  comments from `case "test"` here.] */
function rollReaction(next: GameState, leaderId?: number): { outcome: ReturnType<typeof reactionRoll>["outcome"]; roll: number } {
  if (next.testMode && next.testNextReaction) {
    const outcome = next.testNextReaction;
    const roll = forcedReactionRoll(next, outcome, leaderId);
    delete next.testNextReaction;
    return { outcome, roll };
  }
  if (next.testMode && (next.testNextDie !== undefined || next.testAllDiceRoll !== undefined)) {
    const forced = next.testNextDie ?? next.testAllDiceRoll!;
    delete next.testNextDie; // one-shot; testAllDiceRoll stays armed for the rest of the turn
    const r = reactionRoll(next, forced, leaderId);
    return { outcome: r.outcome, roll: r.roll };
  }
  const r = reactionRoll(next, undefined, leaderId);
  next.seed = r.seed;
  return { outcome: r.outcome, roll: r.roll };
}

/** The Sibyl's one test (SC-SIB-4/5): the real strangers are dealt with and she is the only one left.
 *  She is never hostile (her row), never counts toward the indifference streak or pacifies the area,
 *  and is never retested — `sibylMet` is set whatever the outcome. Friendly: she travels with the party
 *  (`hasSibyl`). Indifferent: she stays in the chamber (parked by the normal exit path). */
function meetSibyl(state: GameState): { state: GameState; events: GameEvent[] } {
  const next = structuredClone(state);
  next.surpriseReady = false;
  delete next.indiffLeaveOpen;
  const { outcome, roll } = rollReaction(next, C_SIBYL);
  const events: GameEvent[] = [{ type: "reaction", outcome, roll }];
  next.sibylMet = true;
  if (outcome === "friendly") {
    next.lulled = (next.lulled ?? []).filter((id) => id !== C_SIBYL);
    next.hasSibyl = true;
    events.push({ type: "sibylJoins" });
  } else {
    events.push({ type: "sibylDeclines" });
  }
  if (next.treasures.length > 0) next.phase = "pickup"; // nothing guards it — she guards nothing
  else persistAndExplore(next);
  return { state: next, events };
}

- [ ] **Step 5: The look component**

Create `apps/web/src/game/SibylLook.tsx`:

```tsx
import { useState } from "react";
import { decodeArea, unpackCoord, type GameAction, type GameState } from "@sorcerers-cave/engine";

type Look = Extract<GameAction, { type: "examineArea" }>;

const SPECIAL_NAME: Record<number, string> = {
  1: "Gateway", 2: "Deep Pool", 3: "Viper Pit", 4: "Tomb", 5: "Great Hall", 6: "Chasm",
  7: "Bell Rope", 8: "Lair", 9: "Whirlpool", 10: "Gallery", 11: "Well",
};

/** A tile card as one readable line: its kind (or special) and the ways out, e.g. "Tunnel — north, south". */
export function describeTile(card: number): string {
  const d = decodeArea(card);
  const ways = [d.n && "north", d.e && "east", d.s && "south", d.w && "west", d.stairUp && "stairs up", d.stairDown && "stairs down"]
    .filter((w): w is string => typeof w === "string");
  const kind = SPECIAL_NAME[d.special] ?? (d.chamber ? "Chamber" : "Tunnel");
  return `${kind} — ${ways.length ? ways.join(", ") : "no exits"}`;
}

/** The Sibyl's free look (SC-SIB-8): the top of the large pack, or any face-down tile on the map. The
 *  card is read from `state` here, in this client only — the action's event carries no card content, so
 *  in multiplayer rivals learn only that this seat consulted her. The readout is local UI state. */
export function SibylLook({ state, actions, dispatch }: { state: GameState; actions: Look[]; dispatch: (a: GameAction) => void }) {
  const [seen, setSeen] = useState<string | null>(null);
  if (actions.length === 0) return null;
  const pack = actions.find((a) => a.area === undefined);
  const tiles = actions.filter((a) => a.area !== undefined);

  const lookPack = () => {
    if (!pack) return;
    dispatch(pack);
    setSeen(`Top of the pack: ${describeTile(state.largePack[state.largeIdx]!)}`);
  };
  const lookTile = (value: string) => {
    const act = tiles.find((a) => String(a.area) === value);
    if (!act) return;
    dispatch(act);
    setSeen(`Tile: ${describeTile(state.areas[act.area!]!.card)}`);
  };

  return (
    <div className="scv-enc-assign">
      <span className="scv-enc-row-nm">The Sibyl</span>
      {pack && <button className="scv-enc-btn" onClick={lookPack}>Look at the top of the pack</button>}
      {tiles.length > 0 && (
        <select className="scv-enc-select" aria-label="Look at a face-down tile" value="" onChange={(e) => lookTile(e.target.value)}>
          <option value="">Face-down tile — choose…</option>
          {tiles.map((a, k) => (
            <option key={a.area} value={a.area}>{`Level ${unpackCoord(state.areas[a.area!]!.coord).level} tile ${k + 1}`}</option>
          ))}
        </select>
      )}
      {seen && <p className="scv-enc-line" data-testid="sibyl-readout">{seen}</p>}
    </div>
  );
}
```
Note the button label contains "the top of the pack" and the test queries `/top of the pack/i`; the select's `aria-label` is `Look at a face-down tile` (matches `/face-down tile/i`).
