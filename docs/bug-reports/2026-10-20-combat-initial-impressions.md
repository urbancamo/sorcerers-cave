
The stranger tactics seem credible so far, but I haven't focussed on that, just the UI, so here
are some initial thoughts:

# Combat UI related - not specific to any individual game

## 1. Unnecessary pauses.

When the attacking player party equals or outnumbers the strangers, there is
no need to pause  between combat step(d) and combat step(e).

There is nothing else the strangers can do after they have put up their defensive line,
so the "confirm initial pairings" interaction with the player is redundant.

But I think players would still value a "roll the round" pause before the dice roll - they want to see how the battle lines match up before rolling the dice. Just psychological, but makes it "feel"
more like a game rather than purely an exercise in probability.

The same would be true when the strangers attack and equal or outnumber a defending player party. In that case the strangers would execute steps (d) and (e) consecutively with no interaction necessary, because this time the player has no choices to make. Still a "roll the round" prompt though.

## 2. Scrolling

The UI should scroll only the battlefield, not the player's "hand of cards".

## 3. Retreat which way?

If retreat is an option, the player needs to be able to see the map
in order to make their decision, but the UI covers most of the screen.

Perhaps the battlefield should shrink before Retreat direction options are shown, then pop back in if the player cancels retreat?
